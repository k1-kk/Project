# 项目介绍

我的个人作品集网站

## 功能列表
- 使用 CSS 编写代码，使页面看起来更加美观
- 通过增减关键词实现切换黑白模式，并通过 localStorage 在用户本地存储状态，实现刷新后能保持
- 通过编写 JaveScript 代码实现功能，可以用 id 标签筛选带有特定 id 的 flex 部分

## 技术栈

- HTML
- CSS
- JavaScript
- 后续计划加入 React 和 TypeScript

## 如何打开页面

- 直接运行 index.html 即可
